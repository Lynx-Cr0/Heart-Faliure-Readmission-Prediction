## 📌 Overview

This machine learning project predicts the risk of **heart failure readmission** based on clinical and demographic patient data. By analyzing health-related patterns in patient datasets, this model aims to identify high-risk individuals who may require additional monitoring or intervention.

> **Note:** This is an educational project for learning ML classification techniques.

---

## 🎯 Objectives

- ✅ Analyze patient health data comprehensively
- ✅ Perform data preprocessing and exploratory data analysis (EDA)
- ✅ Identify key features associated with heart failure readmission
- ✅ Train and compare multiple machine learning classification models
- ✅ Evaluate model performance using appropriate classification metrics

## 🤖 Machine Learning Models

### Classification Algorithms Used:
- **Logistic Regression** - Linear classification model
- **K-Nearest Neighbors (KNN)** - Distance-based classification
- **Decision Tree** - Tree-based classification

### Evaluation Metrics:
- Accuracy
- Precision & Recall
- F1-Score
- Confusion Matrix
- ROC-AUC Curve

---

## 📊 Dataset

The dataset includes clinical information about patients with features such as:

- **Demographics:** Age, Sex
- **Cardiovascular Metrics:** Blood Pressure, Ejection Fraction
- **Lab Results:** Serum Creatinine, Serum Sodium
- **Health Conditions:** Diabetes, Heart Disease History
- **Medications & Lifestyle:** Smoking Status
